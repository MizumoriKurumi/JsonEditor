# JsonEditor

一个基于 C#、.NET 8 和 WinForms 开发的轻量级 JSON 可视化编辑器。

## 功能

- 新建、打开、保存 JSON 文件
- 表格化显示和编辑 JSON 数据
- 修改属性名称及数据类型
- 拖拽调整数据顺序
- 未保存修改提醒
